ORDERS
------
* LISTING ORDERS + STATUS	--> https://sacred-incense.co.uk/admin/orders/
STATUS WE USE: 
	- IN PROGRESS (IN BASKET)
	- ORDERED
	- PENDING ACTION (= ORDERED ORDERS CHECKED we move here, pending payment or waiting for interaction with customer)
	- READY TO PROCESS (READY TO BE PACKED, BUT DOES NOT COME OF STOCK YET)
	- PACKED AND PENDING (TAKEN OFF STOCK HERE)
	- READY TO SHIP
	- SHIPPED
	- DELIVERED (once confirmed by customer)
	- PICKED UP (not shipped, but customer comes and collects parcel at warehouse)
	- BEING RETURNED
	- RETURNED
	- RESHIPPED
	- LOST

COUNTRIES
---------
* Page where we can manage the countries we ship to and selecting what shipper we can enable for that specific country
Different shippers, like POST NL, DHL EXPRESS, DHL PARCEL can be selected/ enabled per country
https://sacred-incense.co.uk/admin/countries/
We have on that page like a BACKOFFICE NOTE, which is important, there we can keep if there have been any issue in the past shipping to that country and leaving notes of past problems, customs issues, returns etc.. Countries with that info have YES in the BACKOFFICE NOTE COLUMN

From current page we use
- NAME
- SHIP VIA
- SHIPPING INSURANCE ENABLED (for post NL included for free, DHL is optional, so if shipper is DHL, then the customer has option to select INSURANCE UPON CHECKOUT, for POST NL COUNTRIES NOT VISIBLE as insurance is already included in price)
- DELIVERY TIME can be set nxt to country and this is also visible in front and on SHIPPING TIME CALCULATOR https://katukina.com/shipping
- SHIPPING NOTE = note that is printed on pick list for the order picker
- CHECKOUT NOTE = note for customer upon checkout, anything we want to be visible for customer we can enter here
- CHECKOUT WARNING = warning for customer upon checkout like "Import duties or local taxes may apply in your country, and the receiver is responsible for payment."
currently we also manually email the customer with a note: for example we email customer in USA to let them know there is import duties to be paid and we want the customer to agree to that, currently via email, but this could be a checkbox.. If not agreed and then the customer has to pay import duties, and the customer can then say i did not know i had to pay import duties and refuse the parcel. then the parcel is returned to us, and with DHL EXPRESS we have to pay to get the parcel back .. so with this note/warning we can avoid and make sure the customer knows and agrees to these things.
Same with Raw Tabaco we ship, we email customer and ask them to check legalities of the items they wish to order. Is buying importing Raw Tabaco allowed? customer needs to accept liability.
